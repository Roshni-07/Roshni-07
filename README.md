## 💭 What Interests Me About Technology

I'm particularly interested in the gap between having an idea and making it useful.

I believe innovation isn't always about inventing something completely new. Sometimes it means recognising a problem that people have learned to live with, finding a gap in an existing solution, or making something complicated more accessible.

I enjoy thinking about questions like:

- What problem are we actually trying to solve?
- What already exists, and where does it fall short?
- What would make a solution more useful or distinctive?
- How can we test whether it works for the people who need it?

I'd like to keep exploring these questions through projects, collaboration, and practical experience.
